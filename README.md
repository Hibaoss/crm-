# CRM Pro - Gestion des Clients

## Description
Ce projet est un CRM (Customer Relationship Management) que j’ai développé pour gérer les clients et leurs informations.

## Fonctionnalités
- Ajout de clients
- Modification des informations
- Suppression de clients
- Interface simple et intuitive

## Technologies utilisées
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Objectif
Ce projet m’a permis de mettre en pratique le développement web full stack et la gestion des bases de données.
